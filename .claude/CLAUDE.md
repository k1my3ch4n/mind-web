## 프로젝트 개요

mind-web은 마인드맵 형태로 웹 페이지의 구조를 설계하고, 그 구조를 바탕으로 실제 동작하는 웹 페이지를 미리 확인해볼 수 있는 프로덕트입니다.

- 마인드맵의 노드는 하나의 웹 페이지를 의미하며, 노드 간 연결은 페이지 간 이동 경로(라우트)를 의미합니다.
- 각 노드(페이지)의 세부 화면에서 해당 페이지의 기본적인 레이아웃을 디자인하고 수정할 수 있습니다.
- 버튼, 모달 등 자주 쓰이는 기본 컴포넌트를 제공하여, 레이아웃을 넘어 프로토타입 수준의 간단한 웹 페이지까지 구성할 수 있습니다.
- 완성된 마인드맵 구조를 기반으로 간단한 웹 페이지를 생성하여 실제 동작을 확인할 수 있습니다.

## 프로젝트 목표

- 새로운 프로젝트나 패키지를 시작하기 전에, 페이지 구조와 라우팅 흐름을 마인드맵으로 빠르게 설계하고 시각화한다.
- 마인드맵 상에서 각 페이지의 레이아웃을 바로 수정하며 구체화할 수 있게 한다.
- 기본 레이아웃뿐 아니라 버튼·모달 같은 기본 컴포넌트를 제공하여, 별도 개발 없이도 동작하는 프로토타입 수준의 웹 페이지를 빠르게 만들 수 있게 한다.
- 설계한 마인드맵을 실제 웹 페이지 형태로 미리 확인하여, 레이아웃과 구조를 사전에 점검하고 팀원과 논의·합의할 수 있는 환경을 제공한다.

## 향후 확장 아이디어

- 완성한 프로토타입을 실제로 호스팅하여 외부에 공유하는 기능 (우선순위는 낮음, 프로토타입 단계 이후에 검토)
- AI 활용 방향
  - 자연어로 서비스를 설명하면 마인드맵(페이지 구조·라우트) 초안을 자동으로 생성
  - 페이지의 목적(로그인, 대시보드 등)에 맞는 레이아웃·컴포넌트 배치를 추천
  - 페이지 내 더미 콘텐츠(텍스트, 카피 등)를 자동으로 채워주는 기능
